# Niel's Birthday Mystery

A small pixel-art birthday mystery game made for Niel. The game runs in a browser and uses plain HTML, CSS, and JavaScript.

## Run it locally

Open `index.html` in a browser, or serve this folder with a local web server such as VS Code Live Server.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the game whenever changes are pushed to `main`. In the repository's **Settings → Pages**, choose **GitHub Actions** as the build and deployment source if GitHub asks for a source.

The published page is public to anyone with its link. The birthday letter is part of the game page.
